# 郝瀚宇 · 成长日记

**Hunter Stuart — A Growth Journal**

一个把个人经历按「离地高度」编排的站点：运载器从发射台升到月球以远，博客首页就是六段轨道。中英双语，`/` 是中文，`/en` 是英文。

不是简历的电子版，也不是日志的堆叠。它想回答的问题是——一个人在成长的不同阶段，世界会以多大的尺度在眼前展开。答案用高度来量。

## 站点形态

### 页面地图

| 路由 | 内容 |
| --- | --- |
| `/` | 欢迎页，两个入口：个人简历 / 博客 |
| `/blog` | 六章轨道博客，翻页浏览 |
| `/profile` | 个人简历 |
| `/posts` | 全部日志 |
| `/posts/<slug>` | 单篇文章 |
| `/gallery` | 相册 |
| `/friends` | 友链 |
| `/tools` | 工具集（三个可交互的小工具） |

`/en` 前缀是英文版，一一对应。语言切换会**保留当前页面**（`/blog` ⇄ `/en/blog`），不是退回首页。

### 一页一屏

博客页不是长滚动。滚轮一次推进一章，六屏叠在同一个固定视口里上下滑动——像翻阅标了刻度的册页，而不是拖着一条无穷长的纸带。

### 两套画风

页头的画笔按钮一键切换，**画风会带着底色一起换**：

| | 水墨 `ink` | 油画 `oil` |
| --- | --- | --- |
| 底色 | 黄白宣纸 `#f4eeda` | 黑星空 `#05050b` |
| 笔画 | 墨黑，朱砂 / 花青 / 石绿写意点缀 | 繁星，朱红 / 电蓝 / 青绿重彩 |
| 肌理 | 纸纤维，`multiply` | 油画笔触，`overlay` |
| 星星 | 整组隐去 | 闪烁 |

纹理不是素材图，是 `scripts/generate-textures.mjs` 用纯 Node 程序化生成的（手写 PNG 编码 + zlib），两张图合计约 92 KB。

## 六章叙事

六个章节对应六个高度，跨越六个数量级：

| 章节 | 高度 | 内容 |
| --- | --- | --- |
| 01 发射台 LAUNCH PAD | 0 km | 简介、精选日志、章节入口 |
| 02 对流层 TROPOSPHERE | 12 km | 技术栈 |
| 03 卡门线 KÁRMÁN LINE | 100 km | 项目 |
| 04 近地轨道 LOW EARTH ORBIT | 400 km | 日志与笔记 |
| 05 地球同步轨道 GEOSTATIONARY | 35,786 km | 日常 |
| 06 月球以远 DEEP SPACE | 384,400 km | 友链、联系 |

从 0 到 384,400 相差六个数量级。如果按线性刻度画右侧的高度轴，前四章会挤成纸边的一个点。所以轴用 `log10`——**视觉上等距，物理上等倍**。

这也解释了为什么选「高度」而不是「时间」当线索：时间只能线性流逝，而高度可以跳数量级。一次考试、一门课、一个项目，在尺度上本来就不在同一个数量级。

## 三个设计取舍

### 一、翻页，而不是无限滚动

长滚动适合「内容流」，不适合「有结构的叙事」。六章是并列的六个阶段，不是六段连续的文字——滚动会让边界消失，读者不知道自己站在哪一章。

翻页的代价是**可发现性**：用户可能不知道要滚。所以右侧有高度轴，随时标出当前位置和总长。

滚轮处理做了三种降级：

- 某章内容高于视口时，滚轮**先让它自然滚完**，抵达边界才翻章
- 触摸设备完全不拦截，保留原生惯性
- `prefers-reduced-motion: reduce` 下不拦截、不播放动画；键盘 `↑ ↓ PageUp PageDown Home` 同样可用

### 二、两套画风，而不是一个「暗色模式」

常见的暗色模式是同一套设计换配色。这里的两套是**两种材质**：水墨讲留白和笔意，油画讲堆积和光。它们不是同一个东西的深浅两个版本。

技术上靠 `<html data-art data-theme>` 两个属性组合出四组色板，全部集中在 `src/styles/tokens.css`。

### 三、零框架运行时

博客页的翻页逻辑（`src/scripts/orbit-journey.ts`）是原生 TypeScript，构建时内联进 HTML，**没有额外的 JS 请求，也没有框架运行时**。

这条原则在工具页有一个例外：史密斯圆图是从外部项目移植的 React 组件，所以引入了一个按需加载的 island。它 208 KB 的 React runtime **只在 `/tools/smith-chart` 加载**——首页、博客、另外两个工具页的 `astro-island` 数量都是 0。

功能和体积之间，这次选了功能；但把代价限制在一页之内。

## 轨迹系统

六章各有一条可见轨迹，运载器和轨道**共用同一套 viewBox 坐标**，永远贴在线上。三种运动模式：

| 模式 | 章节 | 运动 |
| --- | --- | --- |
| `static` | 发射台 | 完全静止待发：与地平线齐平、未点火、尾焰隐藏 |
| `climb` | 对流层 | 翻到这一屏时点火发射，之后沿上升轨道单向划过 |
| `orbit` | 其余四章 | 绕真实天体做椭圆环绕，360° 连续循环 |

环绕不是关键帧插值（那会在采样点之间抖动），而是六层嵌套变换：先把圆压扁成椭圆，转到角度，推到轨道半径上，再**反向压扁、反向旋转**——让卫星本身不变形、姿态始终朝上。

运载器形态随章节推进：完整构型 → 助推器分离 → 只剩芯级 → 整流罩外翻露出卫星 → 太阳翼展开 → 缩小远去。

## 工具页

三个独立的可交互工具，都能在浏览器里直接算：

| 工具 | 做什么 | 实现 |
| --- | --- | --- |
| **番茄钟** | 专注 / 短休 / 长休循环，进度存本地 | 原生 TS，圆环 SVG，用结束时间戳计时（标签页休眠不掉秒），Web Audio 提示音 |
| **史密斯圆图** | 阻抗、导纳、反射系数互算；传输线变换；单短截线与 L 型匹配；S1P 导入；SVG / CSV 导出 | 移植的 React 组件，含等电阻圆、等电抗圆、波长与角度刻度 |
| **IIR / FIR 滤波器设计** | 巴特沃斯 / 切比雪夫 I 型 / 窗函数法，实时看幅频、相频、零极点 | 原生 TS + Canvas，含双线性变换预畸变与稳定性判定 |

滤波器那部分的双线性变换补了 `z = -1` 处的零点（s 平面无穷远零点映射过来），否则截止频率处不是 −3 dB。这条是用临时脚本验证频响之后才定下来的。

## 技术栈

| | |
| --- | --- |
| 框架 | Astro 7，静态输出 |
| 交互 | 原生 TypeScript；仅史密斯圆图用 React island |
| 样式 | 原生 CSS，`data-art` × `data-theme` 四组色板 |
| 内容 | Markdown + Content Collections，中英各自独立 |
| 图形 | 内联 SVG（无图片资源）+ Canvas |
| 部署 | GitHub Pages，推 `main` 自动构建发布 |
| 运行时要求 | Node.js 22.23.4+ |

中英是两份**完全独立**的字典，不做缺字段回退。试过回退，但中英长度差异大，按钮、导航这类定宽元素会被撑变形。代价是改文案要改两遍，`npm run i18n:check` 能列出漏掉或雷同的字段。
